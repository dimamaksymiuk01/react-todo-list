# React Todo List

Сучасний застосунок для управління завданнями з історією змін, багатомовністю та темізацією.

---

## Особливості

### Основний функціонал
- ✅ Додавання завдань через валідовану форму з назвою та описом  
- ✅ Історія змін з останніми 10 діями  
- ✅ Скасування дій (undo) для відновлення попереднього стану  
- ⬜ Список завдань з можливістю відмічати виконані та видаляти  
- ⬜ Фільтрація та пошук за статусом та назвою  
- ⬜ Збереження в localStorage для збереження даних між сесіями  

### Додаткові можливості
- Багатомовність (українська та англійська)  
- Перемикання теми (світла/темна)  
- Адаптивний дизайн  
- Debounce для пошуку (оптимізація продуктивності)

## Використання

### Додавання завдання
1. Введіть назву завдання (мінімум 3 символи)  
2. За бажанням додайте опис (мінімум 10 символів)  
3. Натисніть **"Додати завдання"**  

### Фільтрація
- **Всі** — показати всі завдання  
- **Активні** — тільки невиконані  
- **Виконані** — тільки виконані  

### Пошук
Введіть текст у поле пошуку для фільтрації за назвою або описом.  

### Історія
- Переглядайте останні 10 дій  
- Натисніть кнопку **"Скасувати"** для відміни останньої дії  

### Мова та тема
- Перемикач мови: **EN / UA**  
- Перемикач теми: **Світла / Темна**

## Архітектура

### State Management
- **TodoContext** — стан завдань, фільтрів та історії  
- **ThemeContext** — тема застосунку  
- **LanguageContext** — поточна мова інтерфейсу  

### Валідація
- Назва: обов'язкове поле, 3–100 символів  
- Опис: необов'язкове, але якщо є — 10–500 символів  

### Історія змін
Reducer зберігає попередній стан перед кожною дією:  
- Додавання завдання  
- Відмітка як виконане/невиконане  
- Видалення завдання  
(максимум 10 останніх записів)
